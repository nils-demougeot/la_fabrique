{% load static %} {% comment %} Invitation à installer la PWA, proposée une seule fois par appareil, à la première page vue une fois connecté. Jamais affichée dans l'appli déjà installée (display-mode standalone), ni sur ordinateur. Trois parcours selon le navigateur : - Chrome / Edge / Samsung Internet (Android) : le vrai bouton « Installer », branché sur l'événement beforeinstallprompt capturé dans le de header.html (window.__fabBip) ; - Safari et navigateurs iOS : pas d'API d'installation, on montre le geste Partager → « Sur l'écran d'accueil » ; - Android sans beforeinstallprompt (Firefox…) : le chemin par le menu ⋮. Le partial est ré-rendu à chaque navigation htmx (le est remplacé) : le script relit donc l'état à chaque passage et ne s'affiche qu'une fois grâce à la clé localStorage `fab-pwa-proposee`. Pour la rouvrir à la main : window.fabProposerInstallation(). {% endcomment %}

Appli mobile

Installez La Fabrique

Retrouvez vos tissus et vos patrons en un geste depuis l'écran d'accueil, en plein écran, comme une vraie appli.

{# Android / Chrome : installation native #}
{# iOS : geste Partager → Sur l'écran d'accueil #}
  1. 1 Touchez Partager En bas de l'écran, ou dans le menu ⋯ Dans la barre d'adresse, en haut à droite
  2. 2 Choisissez Sur l'écran d'accueil
  3. 3 Touchez Ajouter : l'icône apparaît avec vos applis
{# Android sans API d'installation (Firefox…) : par le menu #}
  1. 1 Ouvrez le menu ⋮ du navigateur
  2. 2 Touchez Installer l'application ou Ajouter à l'écran d'accueil
